## 安装

项目需要 WASM 引擎和目标宿主 adapter。Web 项目使用：

```bash
pnpm add @weapp-sqlite/wasm @weapp-sqlite/web sql.js
```

微信小程序使用：

```bash
pnpm add @weapp-sqlite/wasm @weapp-sqlite/miniprogram sql.js
```

这些 adapter 会依赖下层包，不需要额外安装 core。

## 打开数据库

```ts
import initSqlJs from 'sql.js'
import { openSqliteWasmDatabase } from '@weapp-sqlite/wasm'
import { createIndexedDbSqliteWasmStorage } from '@weapp-sqlite/web'

const database = await openSqliteWasmDatabase(
  options => initSqlJs({ locateFile: options?.locateFile }),
  'app.db',
  {
    locateFile: file => `/assets/${file}`,
    storage: createIndexedDbSqliteWasmStorage(),
  },
)

await database.exec('CREATE TABLE IF NOT EXISTS notes (id INTEGER PRIMARY KEY, body TEXT NOT NULL)')
await database.exec('INSERT INTO notes (body) VALUES (?)', ['hello'])
const result = await database.query<{ id: number, body: string }>('SELECT id, body FROM notes')
await database.close()
```

所有数据库方法都是异步的。`close()` 会先 flush 脏数据，再关闭 WASM 数据库。

## 加载 WASM

构建时确定性复制 `sql.js` 发布包中的 WASM 文件。Web 的浏览器入口会请求 `sql-wasm-browser.wasm`，微信小程序从代码包读取 `sql-wasm.wasm`。不要依赖开发服务器从 `node_modules` 临时解析资源。

Web 的 `locateFile` 必须返回实际静态 URL：

```ts
locateFile: file => `/assets/${file}`
```

小程序构建工具不会自动把 npm 包内的 WASM 文件变成业务资源。`examples/weapp-vite-multi-platform/scripts/sync-sql-wasm.ts` 展示了复制方式，`pnpm acceptance:build` 会检查每个目标产物中的资源。

## 加入迁移

使用 core 提供的 `migrate` 管理版本。迁移版本必须是正整数且唯一，已应用的版本会记录在 `__weapp_sqlite_migrations` 表中：

```ts
import { migrate } from '@weapp-sqlite/core'

const versions = await migrate(database, [
  {
    version: 1,
    name: 'create_notes',
    up: transaction => transaction.exec(
      'CREATE TABLE notes (id INTEGER PRIMARY KEY, body TEXT NOT NULL)',
    ),
  },
])
```
