---
title: Devframe SQLite 面板
description: Web 与微信开发工具中的实时 SQLite 调试连接
---

`@weapp-sqlite/devtools` 提供独立 Devframe 面板、runtime WebSocket broker 和可复用的 Devframe definition。它不会在 Node 端打开数据库；所有查询、写入、导入导出和执行计划都由目标 runtime 中已打开的连接完成。

```bash
pnpm add -D @weapp-sqlite/devtools
```

在 `weapp-vite` 中通过 `debug.devtools` 开启：

```ts
weappSqlite({
  debug: {
    enabled: true,
    devtools: true,
  },
})
```

开发服务日志会输出带一次性 OTP 的面板 URL。宿主认证由 Devframe 管理，runtime 使用独立 token，仅接受 loopback WebSocket；微信开发工具连接使用 `wx.connectSocket`。断线会拒绝待处理请求，写操作不会自动重放，watch 重建复用服务，退出时释放端口和 runtime session。

也可以独立启动宿主：

```ts
import { startSqliteDevtoolsServer } from '@weapp-sqlite/devtools'

const server = await startSqliteDevtoolsServer({ allowWrite: true })
console.log(server.url)
// watcher 退出时：
await server.close()
```

面板支持运行实例和数据库切换、结构管理、绑定参数 SQL、CRUD、SQLite/CSV/JSON 导入导出。SQL 历史按数据库保存最近 50 条，执行计划只调用 `EXPLAIN QUERY PLAN`，不会执行原语句；“性能诊断”会在同一计划上标出全表扫描、临时 B-tree 和自动索引，并说明临时 B-tree 是排序、分组还是去重所需；“诊断”页读取迁移历史与配置定义的差异，并展示外键开关、约束、`foreign_key_check` 违规和按表归属的 schema mismatch。生产构建关闭调试后不会打包面板桥、凭证和 client 资源。
