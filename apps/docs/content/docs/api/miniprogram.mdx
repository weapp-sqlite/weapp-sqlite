---

包名是 `@weapp-sqlite/miniprogram`，协议面向通用小程序平台。首期只内置微信 driver；其他目标需要注入自定义 `MiniProgramHostAdapter`，否则返回明确的不支持结果。

## 平台与入口

```ts
type MiniProgramPlatform = 'weapp' | 'alipay' | 'tt' | 'swan' | 'jd' | 'xhs'

createMiniProgramSqliteWasmStorage(options)
createMiniProgramSqlJsInitializer(options)
loadMiniProgramPackageBinary(path, options)
probeMiniProgramSqliteCapabilities(options)
```

宿主 API 的 `options` 必须显式提供 `platform` 和 `runtime`，可选 `adapter`、`directoryName`、`packageBinaryPath` 和 `webAssembly`。微信应用应把顶层 `wx` runtime 和 `WXWebAssembly` 交给 factory，包内部不直接引用平台 API。

## 微信接入

```ts
import initSqlJs from 'sql.js'
import {
  createMiniProgramSqliteWasmStorage,
  createMiniProgramSqlJsInitializer,
  probeMiniProgramSqliteCapabilities,
} from '@weapp-sqlite/miniprogram'

const options = {
  platform: 'weapp' as const,
  runtime: wx,
  packageBinaryPath: '/assets/sql-wasm.wasm',
  webAssembly: WXWebAssembly,
}

const capability = await probeMiniProgramSqliteCapabilities(options)
if (!capability.supported) {
  throw new Error(`${capability.code}: ${capability.message}`)
}

const storage = createMiniProgramSqliteWasmStorage(options)
const initializer = createMiniProgramSqlJsInitializer({
  ...options,
  initializer: initSqlJs,
})
```

storage 使用 `getFileSystemManager()` 在 `env.USER_DATA_PATH` 下保存数据库，提供 `load`、`save` 和 `remove`。initializer 通过 sql.js 的 `instantiateWasm` 钩子调用 `WXWebAssembly.instantiate()`，因此传入的是代码包路径，不是 `ArrayBuffer`。

`WXWebAssembly` 从微信基础库 2.13.0 开始提供。2.13.0 是技术候选下限，正式最低支持组合仍需由 iOS/Android 真机验收确定。

## 不支持契约

能力探测返回平台、`supported`、失败 capability、稳定错误码和消息。缺少 runtime、文件系统、用户目录、BigInt TypedArray、兼容的 WebAssembly runtime 或包内资源时返回对应失败；实例化拒绝使用 `MINIPROGRAM_SQLITE_WASM_INSTANTIATION_FAILED`，未内置 driver 的平台使用 `MINIPROGRAM_SQLITE_PLATFORM_UNSUPPORTED`。

创建 storage 或读取包资源时，不支持状态会抛出 `MiniProgramSqliteUnsupportedError`。没有 asm.js 或内存数据库降级。
