## 什么时候需要本包

这是新项目的推荐入口。配置一次插件后，业务代码只使用 `openSqlite()`，不感知当前是 Web 还是哪个小程序目标。

`@weapp-sqlite/weapp-vite` 将平台差异留在构建和 adapter 层。应用配置一次插件，业务代码在 Web、微信、支付宝、抖音、百度、京东和小红书保持一致。

```ts
import { weappSqlite } from '@weapp-sqlite/weapp-vite'

export default defineConfig({
  plugins: [weappSqlite({
    debug: {
      enabled: process.env.WEAPP_SQLITE_DEBUG === '1',
      page: { route: '__weapp_sqlite_debug/index/index', configFile: './src/sqlite-debug.config.ts' },
    },
    wasm: {
      variant: 'lite',
      weappPackage: { mode: 'generated-subpackage' },
    },
  })],
})
```

```ts
type SqliteWasmVariant = 'full' | 'lite'

type WeappSqliteWasmPackage =
  | 'main'
  | { mode: 'generated-subpackage', root?: string }
  | { mode: 'existing-subpackage', root: string }
```

默认值为 `full + main`，资源名与旧版本一致。`variant` 对 Web 和全部小程序目标生效；`weappPackage` 只影响微信。自动分包 root 默认是 `__weapp_sqlite__`，生成普通分包、隐藏页、主包 loader 和带所有权标记的 runtime，冲突时构建失败。已有分包必须出现在最终 `app.json.subPackages`，且不能设置 `independent: true`。

自动分包要求 `app.json.ts` 从 `weapp-vite/auto-routes` 写入 `subPackages`；静态 `app.json` 使用已有分包模式。full 的 runtime engine 为 `sql.js-wasm`，lite 为 `sql.js-wasm-lite`。

## Runtime

```ts
import { openSqlite, removeSqlite } from '@weapp-sqlite/weapp-vite/runtime'

const database = await openSqlite({ name: 'app.sqlite', migrations })
await database.query('SELECT * FROM notes')
await database.close()

await removeSqlite({ name: 'app.sqlite' })
```

同名并发打开会返回同一应用级连接；已打开连接的 adapter 或迁移函数不一致时抛出 `SQLITE_OPEN_OPTIONS_CONFLICT`。`openSqlite()` 在返回前完成能力探测和迁移。宿主不满足要求时抛出 `SQLITE_RUNTIME_UNSUPPORTED`，引擎初始化失败时抛出 `SQLITE_ENGINE_INIT_FAILED`。

`getSqliteTarget()`、`getSqliteRuntimeInfo()` 和 `getSqliteDatabasePath()` 用于验收与调试信息。高级集成可以从 `@weapp-sqlite/weapp-vite/adapter` 导入 `SqliteRuntimeAdapter` 并通过 `openSqlite({ adapter })` 覆盖内置实现。

## 数据工作台

```ts
import { defineSqliteDebugWorkspace } from '@weapp-sqlite/weapp-vite/debug'

export default defineSqliteDebugWorkspace({
  databaseName: 'app.sqlite',
  migrations,
})
```

`debug: boolean` 仍兼容并映射到默认路由与配置文件。调试构建生成带所有权标记的 TS/WXML/SCSS/JSON 页面；目标目录已有用户文件时直接失败，不覆盖。Web 将其注册为懒加载路由，小程序将其注册为独立分包。

工作台自动复用当前目标 adapter 的数据库、快照和文件交付能力。生产构建通过编译常量排除 route、写 SQL、CSV/JSON codec、导入逻辑和 `saveFileToDisk` / `shareFileMessage` / `chooseMessageFile`。
