`examples/weapp-vite-multi-platform` 是 Web 与微信多端的正式验收应用。Web 单独构建；微信只生成一份产物，由开发者工具、iOS 微信和 Android 微信共同验收。

## Demo 矩阵

| 目录 | 框架 | 小程序构建 | Web 构建 |
| --- | --- | --- | --- |
| `examples/weapp-vite-multi-platform` | weapp-vite `multiPlatform` | `pnpm --filter weapp-sqlite-demo-weapp-vite build:weapp` | `pnpm --filter weapp-sqlite-demo-weapp-vite build:web` |
| `examples/taro` | Taro 4 + React | `pnpm --filter weapp-sqlite-demo-taro build:weapp` | `pnpm --filter weapp-sqlite-demo-taro build:h5` |
| `examples/uni-app` | uni-app + Vue 3 | `pnpm --filter weapp-sqlite-demo-uni-app build:weapp` | `pnpm --filter weapp-sqlite-demo-uni-app build:h5` |
| `examples/mpx` | MPX + Webpack 5 | `pnpm --filter weapp-sqlite-demo-mpx build:weapp` | - |

## 验证流程

先运行各 demo 的 wiring 测试和类型检查，再运行目标构建：

```bash
pnpm --filter weapp-sqlite-demo-weapp-vite test
pnpm --filter weapp-sqlite-demo-taro test
pnpm --filter weapp-sqlite-demo-uni-app test
pnpm --filter weapp-sqlite-demo-mpx test
```

正式链路使用根目录命令构建 Web 和六个小程序目标：

```bash
pnpm acceptance:build
pnpm acceptance:web
pnpm acceptance:devtools:doctor
pnpm acceptance:devtools
pnpm acceptance:mobile:prepare
pnpm acceptance:verify
```

`acceptance:verify` 只接受当前 commit 的 Web、DevTools、iOS 下限/最新和 Android 下限/最新报告，并要求所有功能检查、设备字段和截图完整。正式准备与汇总必须在干净工作区运行。

## 平台注意事项

- Web 使用 `@weapp-sqlite/web` 的 IndexedDB 二进制持久化，不回退到内存。
- 微信使用 `@weapp-sqlite/miniprogram` 内置文件系统 driver，数据库位于 `USER_DATA_PATH`，sql.js 通过显式注入的 `WXWebAssembly` 加载代码包资源。
- Web 产物只包含 `sql-wasm-browser.wasm`，小程序产物只包含 `sql-wasm.wasm`，避免重复资源占用主包。
- `weapp-vite` demo 的小程序目标包括 `weapp`、`alipay`、`tt`、`swan`、`jd` 和 `xhs`。后五个平台当前只要求构建成功，运行时应返回稳定 `MINIPROGRAM_SQLITE_PLATFORM_UNSUPPORTED`。
- Headless 结果只是逻辑预检。微信支持证据以真实 DevTools 和四组真机报告为准。
